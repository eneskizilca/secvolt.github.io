# SecVolt - Elektrikli Şarj İstasyonu Güvenlik Sistemleri

Modern ve responsive tek sayfalık website, SecVolt şarj istasyonu ve elektrikli şarj sistemi güvenliği firması için geliştirilmiştir.

## Özellikler

- ⚡ **React + Vite** - Hızlı geliştirme ve optimize edilmiş üretim build'i
- 🎨 **Tailwind CSS** - Modern ve özelleştirilebilir tasarım sistemi
- 🌓 **Dark/Light Mode** - Tema değiştirme özelliği
- 📱 **Responsive Design** - Tüm cihazlarda mükemmel görünüm
- ⚡ **Hızlı ve Optimize** - Minimal bundle size ve hızlı yükleme
- 🎯 **Tek Sayfa Navigasyon** - Smooth scroll ile bölümler arası geçiş

## Kurulum

### Gereksinimler

- Node.js (v16 veya üzeri)
- npm veya yarn

### Adımlar

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

3. Tarayıcınızda açın:
```
http://localhost:5173
```

## Build

Üretim için build almak için:

```bash
npm run build
```

Build dosyaları `dist` klasöründe oluşturulacaktır.

## Önizleme

Build'i önizlemek için:

```bash
npm run preview
```

## Bölümler

Website şu bölümlerden oluşmaktadır:

- **Hero** - Ana başlık ve tanıtım bölümü
- **Features** - Özellikler ve hizmetler
- **About** - Hakkımızda ve şirket bilgileri
- **Contact** - İletişim formu ve bilgileri
- **Footer** - Alt bilgi ve linkler

## Tema Değiştirme

Website otomatik olarak kullanıcının sistem tercihini algılar ve dark/light mode arasında geçiş yapar. Kullanıcı manuel olarak da tema değiştirebilir ve tercihi localStorage'da saklanır.

## Özelleştirme

### Renkler

Renkleri özelleştirmek için `tailwind.config.js` dosyasındaki `colors` bölümünü düzenleyin.

### İçerik

Bileşenlerdeki içerikleri `src/components/` klasöründeki ilgili dosyalardan değiştirebilirsiniz.

## Teknolojiler

- React 18
- Vite 5
- Tailwind CSS 3
